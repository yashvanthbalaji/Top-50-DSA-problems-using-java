## 📌 About This Repository

Welcome to **Top 50 DSA Problems Using Java** — a curated collection of the most important **Data Structures and Algorithms interview questions**, solved in **Java** with clean, optimized, and beginner-friendly solutions.

This repository is designed for:

* 💼 Coding Interview Preparation
* 🧠 Strengthening DSA Fundamentals
* 📚 Java Problem Solving Practice
* 🚀 Placement & Competitive Programming Prep

## 📈 Complexity Focus

This repository emphasizes:

* Brute Force ➜ Better ➜ Optimal Approach
* Time Complexity Optimization
* Space Complexity Tradeoffs
Examples:

| Problem                | Optimal Complexity |
| ---------------------- | ------------------ |
| Two Sum                | O(n)               |
| Maximum Subarray       | O(n)               |
| Reverse Linked List    | O(n)               |
| Sliding Window Maximum | O(n)               |
| Coin Change            | O(n × amount)      |
| LRU Cache              | O(1)               |
